Method

  • One manual search per trade per city; first 20 non-sponsored results recorded by hand. Only star rating, review count and listing link were recorded. No review text, photos or map images.
  • Boundary: each city's amalgamated limits. Listing address must be in that city. Addressless listings kept only if a local area code or the name states that city.
  • Dropped: category mismatch, zero reviews, out-of-city. Duplicate listings of one brand count once (larger listing).
  • Only the top 3 per trade by review count are named. Businesses below the median are never named.
  • Full method: METHOD.md.
